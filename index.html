¡Resuelto!

Cómo se juega
  • Objetivo: recuperar el cubo con las caras superiores amarillas, las izquierdas verdes y las derechas rojas.
  • Mueve el puntero: la herramienta de 3 piezas se ajusta al punto de convergencia más cercano.
  • Verde: tres rombos forman un cubito y se pueden girar. Rojo: giro bloqueado.
  • Clic: gira el grupo 60° en sentido horario. Para girar más, vuelve a hacer clic.
  • Cada giro cambia el patrón: un cubito que sobresale pasa a ser un rincón y viceversa.
  • Táctil: toca para seleccionar y vuelve a tocar para girar.
  • Teclado: flechas para mover la selección, E o Enter para girar, Ctrl+Z / Ctrl+Y para deshacer y rehacer.
