¡Resuelto!

Cómo se juega
  • Mueve el puntero: la herramienta de 3 piezas se ajusta al punto de convergencia más cercano.
  • Verde: tres rombos forman un cubito y se pueden girar. Rojo: giro bloqueado.
  • Clic = 120° horario. Mayús+clic o clic derecho = 240°.
  • Táctil: toca para seleccionar y vuelve a tocar para girar.
  • Teclado: flechas para mover la selección, E/Enter = 120°, Q = 240°, Ctrl+Z / Ctrl+Y.
  • Objetivo: caras superiores blancas, izquierdas verdes y derechas rojas.
